# Changelog

The version is in `VERSION`; it goes up with every release.

## 1.2.0 - 2026-11-02

* UI library: display edits (`uilib.edit_display`, `XV2UI_EditDisplay`), so a mod can add a placement to a menu's timeline or change one's matrix, and several mods' edits of one menu stack.

## 1.1.0 - 2026-10-31

* For game version 1.27 (was 1.26.01).
* New UI library (`Lib\XV2UserInterfaceLib.dll`, Lua `uilib`): several mods' edits of the same menu script, texture or text (msg) file are merged, instead of one mod owning the whole file.

## 1.0.0 - 2026-10-15

* First versioned release (everything in the README).
