# Changelog

The version is in `VERSION`; it goes up with every release.

## 1.1.1 - 2026-11-05

* New defaults: `unlock_teleports` is on; `unlock_all_parallel_quests`, `unlock_all_expert_missions` and `unlock_level_cap` are off. Existing config files are not changed.

## 1.1.0 - 2026-10-31

* For game version 1.27 (was 1.26.01). Needs XV2 Mod Loader 1.1.0 or newer.
* Free attribute points now live in an Attributes script shared with Combined Supers, so both mods' changes show together.
* The hidden "Future Saga" menu title art goes through the mod loader's UI library as a single-image edit, so other mods' changes to the same title file still apply (the old whole-file edit remains as a fallback).

## 1.0.0 - 2026-10-15

* First versioned release (everything in the README).
